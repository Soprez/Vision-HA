# Sécurité · Security

Vous pensez avoir trouvé une faille ? **N'ouvrez pas d'issue publique.** Signalez-la en privé par
**Security → Report a vulnerability** sur ce dépôt (GitHub Private Vulnerability Reporting). Indiquez la version
de l'intégration, de l'application ou de l'agent, et comment reproduire. Réponse visée : sous 7 jours.

Found a vulnerability? **Do not open a public issue.** Report it privately with **Security → Report a
vulnerability** on this repository. Include the integration, app or agent version and the steps to reproduce.
We aim to answer within 7 days.

Seule la dernière version publiée reçoit des correctifs. · Only the latest release receives fixes.
